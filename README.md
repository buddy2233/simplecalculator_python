# simplecalculator_python
I am a beginner. This is a calculator, it can do basic calculation's, and has little easter eggs.

 # Features
**Basic math**: Add, subtract, multiply, divide
**Advanced**: Powers, roots, logs, trigonometry 
**Geometry**: Circle area/circumference, Pythagorean theorem
**Algebra**: Quadratic formula solver
**Chemistry**: Basic compound formula creator
**Tools**: Multiplication table, spell checker
**Games**: Number guessing game
 **Easter eggs**: Try typing `bunny`, `dog`, `coffee`, `pc`, `game`
